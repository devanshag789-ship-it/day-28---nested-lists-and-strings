# Day 28 — Nested Lists and String Concatenation

## Learning goals
- Understand a list that contains other lists.
- Access nested data using more than one index.
- Join strings using the `+` operator.

## Key ideas
- `nested_list[0]` accesses the first inner list.
- `nested_list[0][0]` accesses the first item inside the first inner list.
- String concatenation joins strings into a new string.
- Use a space inside one of the strings when you want a visible space between words.
